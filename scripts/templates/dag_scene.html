# Policy Time Machine: Core Orchestration DAGs
for domain in available_domains():
    # 1. Backfill historical decisions point-in-time
    replay_dag = build_replay_dag(domain)
    
    # 2. Human-in-the-loop queue for contested cases
    hitl_dag = build_adjudication_dag(domain)
    
    # 3. Regression test against human rulings
    gate_dag = build_precedent_gate_dag(domain)
    
    # 4. Synthesize amendments from evidence
    propose_dag = build_proposal_dag(domain)
replay_expenses
Replays historical decisions across data intervals, attributes diffs to clauses, and writes evidence to shared memory.
adjudicate_expenses
Routes representative reversals to human reviewers. Decisions become precedent fixtures.
precedent_gate_expenses
Checks proposals against all human precedents. Automatically fails if a proposal overturns human rulings.
